# ADR-0008 主令牌降权为设备会话，并加固 Web 入口

- 状态：已接受（2026-08-15）
- 依据：[ADR-0004](ADR-0004-token-proxy.md)（令牌代理）、[ADR-0006](ADR-0006-pairing-code-and-tls.md)（配对码）、[ADR-0007](ADR-0007-web-mode-launcher.md)（Web 启动页）

## 背景

对 Web 模式做完整审查和真实端到端验证时发现四个问题：配对成功会把长期主令牌返回给客户端；启动页把令牌写入 `localStorage` 并经 URL 查询参数传递；未受信的 `Host` 会进入 `new URL()` 并可能让代理进程异常退出；已认证请求没有在代理层拒绝跨源 HTTP/WS。另有地址标准化错误：显式 `https://host` 会被启动页强行改到 `:3081`，破坏标准 443 和反向代理部署。

主令牌是整台代理的根凭据，同时承担设备会话不利于控制泄漏影响。浏览器已能依赖 HttpOnly Cookie，没有理由让页面 JavaScript 或浏览器持久存储接触任何长期凭据。

## 决策

1. **签名设备会话**：配对码兑换一个带随机 ID 和 30 天过期时间的设备令牌，用主令牌做 HMAC-SHA256 签名。设备令牌可访问代理后的 HTTP/WS，但不能调用 `/pair/new`。旋转主令牌会使全部设备令牌立即失效。
2. **浏览器只接触 HttpOnly Cookie**：Web 配对的响应正文不再返回令牌，直接设置 HttpOnly、SameSite=Lax Cookie；浏览器 `localStorage` 只保存主机地址和时间。新增同源 `POST /session`，把手工输入的主令牌或兼容设备令牌换成 HttpOnly 设备 Cookie；主令牌在落 Cookie 前必须降权。旧 `?token=` 入口只作兼容，成功后同样先降权并跳转到无令牌 URL。
3. **App 兼容路径不再获得主令牌**：带 `x-dsh-client: app` 的配对请求只返回设备令牌。启动页用 URL fragment 将其交给远端同源页面，远端立即清除 fragment 并调用 `/session`，不再使用可能进入访问日志和 Referer 的查询参数。
4. **入口加固**：只接受 origin-form 请求目标，使用固定本地基址解析，`Host` 只做严格验证；畸形 HTTP/WS 返回 400，`clientError` 不得结束进程。已认证的转发 HTTP/WS 必须无 `Origin`，或 Origin 为 HTTP(S) 且 authority 与 `Host` 一致，否则返回 403；比较不绑定代理内部协议，以兼容 Caddy/Nginx 终止 TLS。启动页增加 CSP（Web 响应仅允许同源连接）、`Referrer-Policy: no-referrer`、`nosniff` 与 `no-store`。
5. **地址标准化**：只给未写 scheme 且未写端口的局域网地址补默认 `:3081`；显式 HTTP/HTTPS 保留标准端口和自定义端口，并清除路径、查询参数与 fragment。

## 后果

- 主令牌不再由 Web 配对返回，也不会进入浏览器 Cookie、响应正文、URL 或 `localStorage`；设备凭据泄漏不再具备继续签发配对码的能力。
- 设备令牌为无状态签名，代理仍保持单文件、无数据库部署。代价是当前不能单独吊销某台设备；可通过旋转主令牌吊销全部设备，后续若需要单设备吊销再引入持久化设备注册表。
- 主令牌 Bearer 仍作为脚本和旧客户端的兼容凭据可访问代理，但浏览器入口始终先降权。移除这条兼容能力属于协议破坏，留待明确的主版本升级。
- `/pair` 继续允许 App 跨源兑换；其 6 位码仍受单用、10 分钟过期和源 IP 限速保护。公网部署仍必须使用可信 TLS。
- 被否决方案：
  - **直接随机设备令牌 + 服务端内存表**：代理重启会让全部设备无故掉线，且多实例无法共享，否决。
  - **把设备令牌继续交给 Web JavaScript**：无法满足减少 XSS/浏览器扩展泄漏面的目标，否决。
  - **立即引入数据库和逐设备吊销 UI**：超出本轮 Web 可用性与安全修复范围，否决。

## 取代关系

取代 ADR-0006 中“`POST /pair` 凭码换真令牌”以及 ADR-0007 中沿用该令牌进入 UI 的具体会话模型；不改变两份 ADR 的配对码、可选 TLS 和 Web 启动页架构决策。细化 ADR-0004 的令牌出示方式：旧主令牌入口保留兼容，但浏览器持久会话改为签名设备 Cookie。
